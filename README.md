# Taller Motos — Node.js + Express + MySQL

## Requisitos
- Node.js (v18 o superior)
- MySQL Server (y MySQL Workbench)

## Pasos para ejecutar

1. **Crear la base de datos:**
   Abre `taller_motos.sql` en MySQL Workbench y ejecútalo completo.

2. **Configurar la conexión:**
   Abre el archivo `.env` y coloca tu usuario y contraseña de MySQL (`DB_USER` y `DB_PASSWORD`).

3. **Instalar dependencias y arrancar el servidor:**
   ```bash
   npm install
   npm start
   ```

4. **Abrir la aplicación:**
   Entra a `http://localhost:3000` en tu navegador.
